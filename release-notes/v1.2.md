# Stereo3D Studio 1.2

**Stereo3D Studio is now a depth map creator too** — plus two new depth models: **Lotus** and an experimental
**Lotus-2**, and new layouts for saving depth maps and separate image files.

## Download
**Stereo3DStudio_v1.2_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Upgrading: copy the `models` folder from your previous install into the new folder before installing.
(The installer adds new packages for Lotus, so a fresh install is needed.)

## 🆕 Depth map creator & new layouts
Drop in photos, artwork, renders or videos and get clean depth maps out — useful well beyond 3D video, for compositing,
relighting, displacement, 3D-print reliefs and parallax photos.
- **Depth map only** (new output layout) — just the greyscale depth map (near = bright), for images and videos
  (`name_DEPTH`).
- **Save images as** (Settings → Files):
  - **One 3D image** in the output layout (as before)
  - **Two images: left eye + right eye** — full resolution (`name_L` / `name_R`)
  - **Two images: colour + depth map** (`name_RGB` / `name_DEPTH`)

## 🆕 Lotus depth — sharp detail, made for images, good for video too
[Lotus](https://github.com/EnVision-Research/Lotus) ([paper](https://arxiv.org/abs/2409.18124)) is a diffusion-based
depth model (Stable Diffusion 2, re-trained to predict depth in one step) — the one kijai's
[ComfyUI-Lotus](https://github.com/kijai/ComfyUI-Lotus) runs. Very fine, crisp detail on hair, foliage and small objects.
- Model: [`lotus-depth-d-v2-0-disparity`](https://huggingface.co/jingheya/lotus-depth-d-v2-0-disparity) — deterministic,
  disparity-trained, Apache-2.0. Downloads automatically on first use (about 3.8 GB) with progress shown.
- **Primarily for images:** the new **Images · Lotus (sharp detail)** preset (Lotus at depth resolution 1036, flip TTA,
  edge fix 1, MLBW L2 + inpaint, Half SBS) **loads automatically when you add images**; adding videos switches back.
- **Works well for video too — just slower**, since every frame is processed on its own.

## 🧪 Lotus-2 (experimental) — the most detailed depth, images only
[Lotus-2](https://github.com/EnVision-Research/Lotus-2) ([paper](https://arxiv.org/abs/2512.01030) ·
[project page](https://lotus-2.github.io/) · [weights](https://huggingface.co/jingheya/Lotus-2)) is the FLUX.1-dev-based
successor to Lotus. It's made to fit 16 GB GPUs by converting FLUX to 4-bit during a one-time setup
(Models → **Set up Lotus-2 (experimental)…**). You need a Hugging Face token with the FLUX.1-dev license accepted
(FLUX.1 [dev] Non-Commercial License); setup downloads ~34 GB and keeps ~7 GB. **Images only** — expect minutes per
image; videos are skipped.

## Fixes & polish
- **Images that aren't 16:9** (4:3, 3:2, portrait) now get side bars in each eye, like videos, so side-by-side 3D lines
  up on the Odyssey 3D.
- Cleaner load screen without the light gradient around the edges.
