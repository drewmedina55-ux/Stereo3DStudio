# Stereo3D Studio 1.2

Adds **Lotus depth**, an experimental **Lotus-2**, a new image preset that switches on by itself, a **depth map** layout and two-file image saving.

## Download
**Stereo3DStudio_v1.2_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Upgrading: copy the `models` folder from your previous install into the new folder before installing.

## 🆕 Lotus depth for images
[Lotus](https://github.com/EnVision-Research/Lotus) is a diffusion-based depth model — the one kijai's
[ComfyUI-Lotus](https://github.com/kijai/ComfyUI-Lotus) runs. It predicts depth in a single step and gives very fine,
crisp detail (hair, foliage, small objects), which makes it great for photos and stills. Stereo3D Studio uses the
deterministic disparity model (lotus-depth-d-v2-0-disparity, Apache-2.0); it downloads automatically on first use
(about 3.8 GB). It works for video too, but it has no frame memory, so video can flicker.

## 🆕 Images · Lotus (sharp detail) preset
Lotus at depth resolution 1036, flip TTA, edge fix 1, MLBW L2 + inpaint, Half SBS. **Adding images switches to it
automatically**, and adding videos afterwards switches back to the settings you had before. Turn this off in
Settings → Files.

## 🧪 Lotus-2 (experimental, images only)
The FLUX.1-dev-based successor to Lotus — the most detailed depth in Stereo3D Studio. Made to fit 16 GB GPUs by
converting FLUX to 4-bit during a one-time setup (Models → **Set up Lotus-2 (experimental)…**). You need a Hugging Face
token with the FLUX.1-dev license accepted (FLUX.1 [dev] Non-Commercial License); setup downloads ~34 GB and keeps
~7 GB. Expect minutes per image; videos are skipped.

## 🆕 Depth map only
A new output layout that saves just the greyscale depth map (near = bright) — for images and videos (`name_DEPTH`).

## 🆕 Save images as two files
Settings → Files → **Save images as**: one 3D image (as before), **two images — left + right eye** at full resolution
(`name_L` / `name_R`), or **two images — colour + depth map** (`name_RGB` / `name_DEPTH`).

## Fixes & polish
- **Images that aren't 16:9** (4:3, 3:2, portrait) now get side bars in each eye, like videos, so side-by-side 3D lines
  up on the Odyssey 3D instead of looking broken.
- The first Lotus download now shows its progress in the queue and the log.
- Cleaner load screen without the light gradient around the edges.
