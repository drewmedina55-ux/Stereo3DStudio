# Stereo3D Studio 1.4

Adds **SHARP 3D scene** — an experimental new way to make the second eye, using Apple's SHARP.

## Download
**Stereo3DStudio_v1.4_Setup.exe** — a standard Windows setup wizard: run it, click through, and start Stereo3D Studio
from the Desktop or Start menu. No admin rights needed. To update later, install into the same folder: your downloaded
models are always kept. Uninstall from Windows Settings → Apps (it asks before deleting models).

Prefer the zip? **Stereo3DStudio_v1.4_Setup.zip** — extract it and run `Install Stereo3D Studio.bat` (copy the `models`
folder from your previous install first).

## 🧪 SHARP 3D scene (experimental)
[SHARP](https://github.com/apple/ml-sharp) ([paper](https://arxiv.org/abs/2512.10685) ·
[examples](https://apple.github.io/ml-sharp/)) is Apple's single-image view-synthesis model. Every other method shifts
pixels along a depth map; SHARP instead turns the picture into a **3D scene of about a million Gaussian splats** (two
layers, so there's something behind foreground objects), and Stereo3D Studio films it with **two virtual cameras**.
Edges and revealed areas come from real geometry — no stretching or smeared fill-in.

- **Use it:** Settings → 3D → Method → **SHARP 3D scene**. 3D strength and Screen plane work as usual.
- **Images, folders and videos.** All layouts except VR180, the 16:9 side bars, Save images as (left + right /
  colour + depth) and Depth map only. Videos are converted frame by frame with sound; the depth range is smoothed
  between frames to keep the 3D steady. Video still takes seconds per frame: use the new preset
  **★ Experimental · SHARP 3D scene (Odyssey)**, keep **SHARP render** at 1080p (720p for quick tests), and try
  Conversion preview on a clip first.
- **Nothing to compile:** Stereo3D Studio renders the splats with its own PyTorch renderer instead of gsplat.
- **Download once:** Models → Apple SHARP → accept the license → Download (2.7 GB from Apple). The weights are under
  the Apple Machine Learning Research Model License — research use only, non-commercial.
