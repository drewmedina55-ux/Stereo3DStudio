# Stereo3D Studio 1.4

A **standard Windows setup wizard**, and **experimental SHARP 3D** — Apple's 3D-scene method — for **images and
video**.

## Download
- **Stereo3DStudio_v1.4_Setup.exe — the new setup wizard (recommended).** Run it, click through, and start
  Stereo3D Studio from the Desktop or Start menu.
- **Stereo3DStudio_v1.4_Setup.zip** — the classic package: extract it and run `Install Stereo3D Studio.bat`
  (copy the `models` folder from your previous install first).

Windows may show *"Windows protected your PC"* for the setup wizard because it isn't code-signed — click
**More info → Run anyway**.

## 🆕 New installer — standard Windows setup wizard
- The usual **Welcome → License → Components → Folder → Install → Finish** steps, with the Stereo3D Studio logo.
- **No admin rights needed.** Installs for your Windows user, by default to `%LOCALAPPDATA%\Programs\Stereo3D Studio`
  (you can pick any folder).
- **Components:** Desktop shortcut and the **Depth Anything V2 Large** model (1.3 GB, CC BY-NC 4.0 — untick it to
  download later from the Models window).
- **Live setup log:** the wizard shows every step while it downloads a private Python 3.12, the PyTorch CUDA build
  that matches your driver and the 3D engine's packages (usually 5–20 minutes). Nothing is installed system-wide.
- **Finish page** with **Start Stereo3D Studio**; Start-menu entry; listed in **Windows Settings → Apps**.
- **Updates keep your models:** install a newer version into the same folder and only the program files are
  replaced — downloaded models, settings and presets stay. Running the setup again repairs an install.
- **Uninstall** from Windows Settings → Apps. It **asks before deleting your models** (default: keep them).

## 🧪 Experimental: SHARP 3D scene — images and video
[SHARP](https://github.com/apple/ml-sharp) ([paper](https://arxiv.org/abs/2512.10685) ·
[examples](https://apple.github.io/ml-sharp/)) is Apple's single-image view-synthesis model. Every other method shifts
pixels along a depth map; SHARP instead turns the picture into a **3D scene of about a million Gaussian splats** (two
layers, so there's something behind foreground objects), and Stereo3D Studio films it with **two virtual cameras**,
one per eye. Edges and revealed areas come from real geometry — no stretching or smeared fill-in.

**How to use it**
- Pick the preset **★ Experimental · SHARP 3D scene (Odyssey)**, or choose Settings → 3D → Stereo generation →
  **Method → SHARP 3D scene (experimental · Apple)** (listed right under MLBW L2 + inpaint). The depth model menu greys
  out — SHARP brings its own depth. **3D strength** and **Screen plane** work as usual.
- First time: Models → **Apple SHARP — 3D scene method** → accept the license → Download (2.7 GB from Apple).

**Images**
- Pictures and folders of pictures, rendered at up to 4K and saved at the source size.
- Every layout except VR180: Half / Full SBS, top-bottom, cross-eyed, anaglyph, 16:9 side bars, **Save images as**
  (left + right, colour + depth), RGB + depth and **Depth map only**. **Preview frame** shows the result instantly.

**Video**
- Converted **frame by frame** — every frame becomes its own 3D scene — with sound, Processing size, FPS limit, codec,
  title, live view and Stop / Pause as usual. **Conversion preview** and **Moments preview** work too.
- **Steadier 3D:** the scene's depth range is smoothed between frames (**Smooth depth between frames**), so 3D strength
  and the screen plane don't jump around; it restarts at scene cuts.
- **New SHARP render setting** (under Method): **Fast — 720p** (about twice as fast, for quick tests),
  **Balanced — 1080p** (recommended — SHARP's own detail is about 768 pixels, so it loses very little) or
  **Full — processing size**.
- **The preset** sets SHARP, Half SBS, 1080p processing, Balanced render, 30 fps (a 60 fps video is half the work),
  FP16 on the GPU, depth smoothing and the NVIDIA hardware encoder.
- **Built for speed:** the splat renderer draws each frame in strips so its memory stays small and never spills out
  of the graphics card (which would make video crawl), renders each eye straight at its
  final size (half width for Half SBS) and skips the eyes for depth layouts. Expect **seconds per frame**, not frames
  per second — try Conversion preview on a clip first, and use Fast — 720p if it's still too slow.
- Some flicker can remain, since SHARP looks at each frame on its own.

**Good to know**
- Experimental: VR180 isn't supported with SHARP yet.
- **Nothing to compile:** Stereo3D Studio renders the splats with its own PyTorch renderer instead of gsplat, which
  would need a CUDA compiler on your PC. Large splats are drawn in full, for clean, accurate results.
- SHARP's weights are under the **Apple Machine Learning Research Model License — research use only,
  non-commercial**. They aren't included; you download them from Apple and accept the license yourself.
