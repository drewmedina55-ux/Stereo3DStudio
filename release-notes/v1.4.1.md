# Stereo3D Studio 1.4.1

**Faster SHARP 3D** — several seconds saved on every image and video frame, and a 720p SHARP render by default for
a usable video speed.

## Download
- **Stereo3DStudio_v1.4.1_Setup.exe — setup wizard (recommended).** Install into the same folder as 1.4 to update:
  your downloaded models are always kept.
- **Stereo3DStudio_v1.4.1_Setup.zip** — classic package (copy your `models` folder into the new folder first).

Windows may show *"Windows protected your PC"* for the setup wizard because it isn't code-signed — click
**More info → Run anyway**.

## What's new
- **SHARP is several seconds faster per frame.** Apple's SHARP code sent all ~1.2 million splats to the CPU on every
  frame to take their shapes apart, and the renderer then rebuilt the very same shapes. Stereo3D Studio now keeps the
  splat shapes on the graphics card and skips that step entirely. The output is identical.
- **SHARP render now defaults to Fast — 720p**, in the settings and the **★ Experimental · SHARP 3D scene image (Odyssey)**
  preset: about twice as fast as 1080p and a usable speed for video. The output is still 1080p; pick
  Balanced — 1080p for a little extra sharpness.
- The method is now listed as **SHARP 3D scene (experimental · Apple · jerg-git)**.
- The SHARP preset is renamed **★ Experimental · SHARP 3D scene image (Odyssey)**.
- Videos keep their original audio with SHARP, as with every other method.
- Faster start for SHARP on NVIDIA GPUs (cuDNN picks the fastest kernels for SHARP's fixed input size).
