# Stereo3D Studio 1.0.1

Much faster 4K conversions.

## Download
**Stereo3DStudio_v1.0.1_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Upgrading from 1.0: copy the `models` folder from your 1.0 folder into the new folder before installing.

## What's new
- **Processing size** setting in the Video tab, default **1080p**. 4K videos are scaled down before converting, which is
  several times faster and stays inside GPU memory. Pick 1440p, 4K or Source size when you want the extra detail.
- Videos larger than 1080p automatically use a smaller batch so they don't overflow GPU memory (which made 4K clips
  crawl — hours for a few seconds of video).
