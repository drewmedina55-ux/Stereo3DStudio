# Stereo3D Studio 1.0.3

## Download
**Stereo3DStudio_v1.0.3_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Upgrading: copy the `models` folder from your previous install into the new folder before installing.

## What's fixed
- **"Invalid argument returned 22"** on some phone and stock-site videos. These use full-range colour (`yuvj420p`)
  or 4:2:2 / 4:4:4 colour, which the GPU-decode (NVDEC) path can't handle. Stereo3D Studio now detects them and
  decodes them on the CPU automatically — depth and encoding still run on the GPU.
