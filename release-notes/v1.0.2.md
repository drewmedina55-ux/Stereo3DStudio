# Stereo3D Studio 1.0.2

Fixes 3D for 4:3 videos such as DVDs, classic cartoons and old TV shows.

## Download
**Stereo3DStudio_v1.0.2_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Upgrading: copy the `models` folder from your previous install into the new folder before installing.

## What's fixed
- **4:3 videos:** each eye now gets black side bars so the side-by-side (or top-bottom) frame is 16:9. 3D displays
  like the Odyssey 3D split the screen exactly in half — a 4:3 SBS frame that the player shrank to fit put each eye
  in the wrong place, so the 3D looked broken. Video tab → **Fit 4:3 videos to 16:9** (on by default).
- **DVD pixels:** 720×480 / 720×576 videos with non-square pixels are converted to square pixels first, so the
  picture keeps its true shape instead of looking stretched.
