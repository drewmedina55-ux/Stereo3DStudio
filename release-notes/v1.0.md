# Stereo3D Studio 1.0

2D → 3D image & video converter for Windows with NVIDIA GPU acceleration, made for the Samsung Odyssey 3D.

## Download
**Stereo3DStudio_v1.0_Setup.zip** — extract it, run `Install Stereo3D Studio.bat`, then start Stereo3D Studio from the Desktop shortcut.
Requires Windows 10/11 64-bit and an NVIDIA GPU with a current driver (about 7 GB disk space).

## Highlights
- Nine 3D output modes: Half / Full SBS, Half / Full Top-Bottom, VR180, cross-eyed, anaglyph, RGB + depth
- Half SBS output and Odyssey 3D presets (Depth Anything V2 Large, MLBW + inpaint, flip TTA)
- Queue with thumbnails and a live view window while encoding — pin it to the app or let it float
- NVENC / NVDEC / CUDA throughout, automatic recovery from GPU out-of-memory errors
- Titles that fade in, hold and fade out at the start or end — font, placement, opacity and 3D depth
- Settings stored inside every output video — drop it back in to restore them

## ⭐ Conversion preview reel
Judge your settings on a whole movie in about a minute instead of converting all of it.
Select a video and click **Conversion preview**: Stereo3D Studio picks random moments spread evenly from the start
to the end of the film (by default 8-second moments adding up to 60 seconds), joins them with their sound, and converts
that reel with your current settings. You get a short 3D sizzle reel showing how the depth looks in dialogue, action,
dark scenes and wide shots — then tweak the settings and run another reel (each click picks new moments), or press
**Convert to 3D** when it looks right. Reel length and moment length are adjustable.
